# English for Work. And Beyond. Progress reports

Static copy of the student progress report site, published with GitHub Pages.

Each student opens the page with a personal link that ends in their own code (`...#code`).
The report data is stored encrypted in `data/`. The page decrypts it in the browser with the code
from the link, so the files cannot be read without it.

Do not edit `index.html` or `data/` by hand. They are generated by `tools/build_static.py`
(see the docstring at the top of that file). The link codes are not stored in this repository.
